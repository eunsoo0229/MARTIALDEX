# 영상 큐레이션 (data/curated/videos.json)

이 폴더의 `videos.json`은 **YouTube Data API를 전혀 사용하지 않고**, 웹 검색으로
직접 찾아서 사람이 확인한(또는 확인 가능한 근거를 남긴) 영상만 등록한 수동 큐레이션
데이터입니다. `scripts/parse-techniques.mjs`(2단계 파서)의 출력물이 아니며,
`npm run parse`를 다시 실행해도 **덮어써지지 않습니다** — 앱은 이 파일을 별도로
읽어서 각 기술의 `videos` 필드에 런타임에 합쳐 넣습니다(`src/lib/loadData.ts`).

## 구조

```json
{
  "bjj__armbar": [
    { "title": "실제 영상 제목", "videoId": "실제 11자리 유튜브 ID", "channel": "채널명" }
  ],
  "judo__juji-gatame": []
}
```

- 키는 `data/processed/<martialArt>.json`의 기술 `id`와 정확히 일치해야 합니다.
- 기술당 **최대 2개**.
- 검증하지 못한 영상 ID는 절대 넣지 않습니다. 좋은 영상을 못 찾은 기술은 **키를 생략**하거나
  빈 배열 `[]`로 둡니다(둘 다 앱에서는 동일하게 "영상 없음"으로 처리됨).

## 선정 기준

1. 그 기술을 실제로 설명/시범하는 튜토리얼 영상
2. 영상 제목에 기술명이 명확히 들어있거나 내용상 그 기술을 다루는 것이 분명함
3. 신뢰할 수 있는 무술/격투기 교육 채널 우선
4. 화질·설명 품질이 괜찮은 영상
5. 단순 경기 하이라이트·쇼츠 제외
6. 같은 기술에 중복 영상 등록 금지
7. 실제로 존재하는 영상인지 확인(검색 결과의 실제 URL에서 videoId 추출)
