# 자세 설명(posture) 데이터 진행 상황

`data/curated/posture.json`을 무술별로 단계적으로 채우는 작업의 진행 기록입니다.
이 파일은 **어디까지 처리했는지**와 **왜 특정 기술을 건너뛰었는지**를 다음 세션이
그대로 이어받을 수 있도록 기록합니다.

절대 규칙(계속 지킬 것):
- 기존 1,253개 기술 데이터(`data/processed/*.json`)는 삭제/이름변경/수정하지 않는다.
- 이미 `posture.json`에 있는 항목은 절대 덮어쓰지 않는다(병합 스크립트는 `if (current[id]) skip` 로직을 항상 유지할 것).
- 확신 없는 기술은 억지로 채우지 말고 "자세 설명 준비 중"으로 남긴다(스킵 목록에 사유와 함께 기록).
- 작업 도중 중단(컴퓨터 절전, 응답 중단 등) 가능성을 고려해 **각 하위 배치(20~30개 단위)마다 병합 스크립트를 실행해 즉시 파일에 저장**한다 — 절대 큰 배치를 한 번에 다 작성한 뒤 마지막에 한꺼번에 저장하지 않는다.
- 새 세션은 이전 응답이 어디까지 실제로 저장됐는지 **절대 추측하지 말고**, 먼저 `data/curated/posture.json`을 직접 읽어 실제 저장 여부를 확인한 뒤 이어서 진행한다.

각 무술 섹션에 사유가 기록되어 있습니다. 새로운 무술이 추가되지 않는 한 이 프로젝트의
남은 작업은 없습니다.

만약 향후 새 무술이 추가되거나 스킵 항목을 재검토해야 할 경우, 아래 순서를 따릅니다:

1. 먼저 아래 명령으로 **실제** 저장 상태를 확인 (절대 이전 대화 내용으로 추측하지 않기):
   ```js
   const fs = require('fs');
   const posture = JSON.parse(fs.readFileSync('data/curated/posture.json','utf8'));
   console.log('총 posture 항목 수:', Object.keys(posture).length);
   ```
2. 대상 무술의 카테고리별 실제 id 목록 추출:
   ```js
   const d = JSON.parse(fs.readFileSync('data/processed/<martial-art-id>.json','utf8'));
   const remaining = d.techniques.filter(t => !posture[t.id]);
   console.log(remaining.length, '개 남음');
   ```
3. `data/curated/posture.json`을 직접 덮어쓰지 말고, "새 항목만 담은 객체 + 병합 스크립트"로 15~25개씩 나눠 추가한다.
4. **각 하위 배치마다 즉시 병합 스크립트를 실행해 파일에 저장한다** — 중단에 대비해 절대 미루지 않는다.
5. 이름이 모호하거나, 여러 하위 개념을 나열한 요약이거나, 다중 동작으로 구성된 전체 형(form)이라 하나의 자세로 규정할 수 없는 항목은 스킵하고 이 파일의 스킵 목록에 사유를 기록한다.
6. 각 무술을 마친 뒤 반드시:
   - `npx tsc --noEmit`
   - `npm run build`
   - 전체 스키마/가짜id 검증 스크립트 재실행
   - 몇 개 기술을 실제 Electron 앱에서 열어 자세 섹션이 정상 표시되는지 확인
   - 기존 회귀 스위트(`qa-posture.mjs`, `qa-full.mjs` 등) 재실행
   - 이 파일의 "전체 현황"/"무술별 진행 상황" 표를 갱신
