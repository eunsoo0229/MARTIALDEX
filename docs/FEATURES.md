### 그래플링 Gi / No-Gi
- 그래플링 기술(주짓수·유도·레슬링·삼보, MMA 그래플링 분류)마다 Gi·No-Gi 분류가 있습니다: 공통(차이 있음) / Gi 중심 / No-Gi 중심 / 실질적으로 동일 / 판단 보류. 분류마다 근거(앱 데이터 또는 웹 자료 인용)와 판단 방법이 함께 표시됩니다.
- 상세 화면의 `[Gi] [No-Gi]` 탭을 바꾸면 자세 설명과 영상 목록이 함께 바뀝니다. 해당하지 않는 스타일은 비활성화되고, 자료가 없는 스타일은 "미등록 / 검토 필요"로 표시합니다(다른 스타일 내용을 빌려 쓰지 않음).
- AI가 정리한 스타일별 자세에는 "AI 조사 · 검토 전" 표시와 출처가 붙습니다.
- 새로 추가하는 그래플링 기술도 등록할 때 웹 자료로 Gi·No-Gi 분류와 스타일별 자세를 조사해 기술과 함께 저장합니다(`lib/grappling/analyzeNewTechnique.ts`). 근거가 부족하면 판단 보류로 두고, 상세 화면에서 "Gi / No-Gi 조사하기"로 다시 조사할 수 있습니다(결과는 이 기기에 저장). 이전에 추가된 기술은 `scripts/backfill-add-teq-gi-nogi.mjs`로 채웠습니다.
- 데이터: `data/curated/gi-nogi.json` (`scripts/build-gi-nogi.mjs`), 감사: `node scripts/audit-gi-nogi.mjs --check-videos` → `docs/GI_NOGI_AUDIT.md`.

## 4. AI 코치 (`/coach`)

**AI 기능 전체 모음:** MARTIALDEX의 AI 기능 26개를 이 탭 한곳에서 시작합니다.
- 분류는 6개이고, 분류 탭과 검색으로 찾을 수 있습니다: 수업·코칭 5, 기술·콤보·전술 7, 커리큘럼·복습 3, 분석 4, 홈트·헬스·영양 6, 기록 1.
- 다른 화면 안에 있는 AI 기능은 카드에 위치를 함께 적어 두었습니다.
- 내 학습 상태, 오늘의 코칭, 개선이 필요한 기술 TOP 5도 이 탭에 있습니다.

### 4-1. 수업하고 싶은 거 입력하기 (`/coach/lesson`) — AI
- **오늘 수업 만들기**
  - 배우고 싶은 것을 말하면 실시간 웹 검색 자료로 오늘 하루짜리 수업을 만듭니다. 커리큘럼은 만들지 않습니다.
  - 특정 기술을 말하면 MARTIALDEX 기술 데이터도 함께 씁니다.
- **1:1 대화형 수업**
  - 짧은 설명 → 질문 → 답변으로 이해도 판단 → 필요하면 다른 방식으로 다시 설명, 순서로 진행합니다.
  - 학생 질문에 먼저 답한 뒤 원래 수업으로 돌아갑니다.
  - 상황 판단 문제와 마지막 복습이 있습니다.
- **음성 대화**
  - 코치 안내를 음성으로 읽어 주고 일시정지·중지할 수 있습니다. 실제로 재생됐는지 확인하고, 실패하면 이유를 표시합니다.
  - 학생은 마이크로 말해 답하거나 질문할 수 있습니다. 녹음한 말은 AI가 받아 적습니다.
- **수업 영상:** 수업 주제에 맞는 YouTube 교육 영상을 검색하고, 영상 정보를 확인한 뒤 앱 안에서 재생합니다.
- **세트·휴식 타이머**
  - 코치의 실습 안내("3분씩 3세트, 세트 사이 1분 휴식")를 그대로 타이머로 바꿉니다. 안내에 없는 값은 지어내지 않고 직접 정하게 합니다.
  - 일시정지·재개·종료가 있고, 새로고침하거나 앱을 벗어났다 와도 실제 경과 시간 기준으로 이어집니다.
- **음성 응원:** 세트 절반, 마지막 30초, 휴식 중 다음 세트 예고, 세트 전환 때 안내합니다. 강도는 끄기 / 최소 / 보통 / 자주 중에서 고릅니다.
- **내 기록 분석·추천 (이전 AI Personal Coach):** 훈련 기록을 근거로 부족한 부분과 추천 기술·훈련을 알려 주고, 바로 수업이나 커리큘럼으로 이어 줍니다.
- 수업이 끝나면 훈련 기록에 한 번 저장합니다(실습 세트와 실제 운동 시간 포함).

### 4-2. AI 코치 수업 (`/coach/class`) — AI
- 운동 장소(집/체육관, 가진 장비)와 배운 기술·숙련도로 AI가 수업 커리큘럼을 만듭니다.
- 각 Day를 AI 코치와 1:1 수업으로 진행합니다(`/learning/:무술/:커리큘럼/coach/:day`).
  - 개념별로 이해도를 확인하고, 수행 전후에 질문합니다.
  - 기술 영상을 보고, 실습 타이머와 시간 안내가 있습니다.
- 개념별 이해도가 학습 기록으로 남아, 다음 수업에서 어려웠던 부분을 다시 짚습니다.

### 4-3. AI Visualizing Mitt (`/coach/mitt`) — AI
- 미트나 파트너 없이 화면의 미트 위치·목표 지점·발 위치를 보며 타격 콤보와 테이크다운 진입을 반복합니다.
- "잽으로 가드를 열고 바디로 연결하는 콤보"처럼 말하면 AI가 콤보나 셋업을 만들어 줍니다.

## 5. 사용자 콤보·셋업 (`/user-combos`)

- **공유:** 콤보 북이나 전술 셋업에서 "🔗 공유"를 누르면 모든 사용자가 볼 수 있습니다.
  - 종류(콤보/셋업)와 목적(예: 잽을 맞추기 위한 셋업)을 함께 올립니다.
  - 같은 항목을 다시 공유하면 새로 생기지 않고 기존 공유가 갱신됩니다.
- **하트(♥):** 한 사람당 한 번만 누를 수 있습니다. 하트 수는 서버가 실제 개수로 계산해 조작할 수 없고, 누가 눌렀는지는 공개하지 않습니다.
- **정렬:** 맞춤 추천 / 이번 주 인기 / 이번 달 인기 / 올해 인기 / 역대 인기 / 최신순 / 하트 적은 순.
- **맞춤 추천:** 사용자가 보는 콤보의 목적을 분석해 관심 있는 목적의 콤보·셋업을 맨 위에 올리고, 추천 이유를 보여 줍니다.
  - 목적은 타격 적중, 테이크다운, 카운터 등 13종과 기술로 분류합니다.
  - 열어 봄·하트·즐겨찾기에 가중치를 주고, 오래된 관심은 줄여서 반영합니다.
- **상세** (`/user-combos/:id`):
  - 목적과 기술 순서, 단계별 설명·작성자 메모·자세 안내를 보여 줍니다.
  - 하트, 즐겨찾기, "내 콤보 북에 담기", 작성자는 공유 취소를 할 수 있습니다.
  - 맨 아래에 관련 추천 콤보·셋업이 나옵니다.
- 필터는 콤보/셋업, 무술, 검색입니다. 목록과 상세는 로그인 없이 볼 수 있고, 공유와 하트는 로그인이 필요합니다.

**복습 기록**
- 복습은 훈련 기록과 따로 저장됩니다(`review_logs`). 복습해도 훈련 횟수·연습 날짜는 늘지 않고, 다음 복습 예정일만 뒤로 밀립니다.
- AI 코치 수업이 끝나면 짧은 수업 요약을 저장합니다(`coach_lesson_logs`). 전체 대화는 저장하지 않습니다.

**데이터 저장 원칙**
- 개인 데이터는 기기에 먼저 저장하고, 로그인하면 본인만 읽을 수 있는 Supabase 테이블로 동기화합니다(RLS).
- 다른 사용자와 공유되는 것: 사용자 추가 기술(`add_teq`), 커뮤니티 게시물, 마켓 커리큘럼, 사용자 콤보·셋업(`shared_combos`), 체육관 데이터.
- AI에는 집계된 훈련 숫자만 보내고, 이메일·이름·사용자 ID는 보내지 않습니다.

## 10. 알려진 상태와 남은 작업

- **결제:** 토스페이먼츠 테스트 결제만 지원합니다.
- **DB 마이그레이션 0036**(`ground_battle_matches` 테이블 삭제)은 아직 실제 서버에 적용하지 않았습니다. 0037(사용자 콤보·셋업)은 적용했습니다. **0038**(복습 기록·수업 요약 테이블)도 적용했습니다(2026-10-16, 두 계정으로 본인 행만 접근되는지 실서버에서 확인).
- **Gi/No-Gi 분류:** 웹 근거로 판단하지 못한 276개는 사용자가 직접 판단해 반영했습니다(`data/curated/gi-nogi-user.json`, 화면에 "사용자 판단"으로 표시). 이 중 공통(차이 있음) 기술의 스타일별 자세 설명은 아직 없어 "미등록 / 검토 필요"로 표시됩니다.
- **이전 복습 기록:** 예전 버전이 훈련 기록에 남긴 "복습"(source `review`) 항목은 지우지 않았고, 전 훈련 복습 목록에서만 제외합니다.
- **한국어 기술 이름 인식:** 기술 데이터에 영어 이름만 있는 기술이 많아, "잽으로 거리 조절"처럼 한국어로 말하면 수업 생성이 AI 판단에 맡겨집니다.
- **가짜 AI 응답 장치:** 일부 QA 스크립트(`qa-coach`, `qa-sparring`, `qa-mystyle`, `qa-fighter-style` 등)가 쓰는 장치(`__MARTIALDEX_TEST_MOCK_ASK__`)가 앱에 없어, AI 응답이 필요한 항목은 실패합니다.
- **Android:** 음성 재생·마이크·영상 등 이번 AI 코치 기능은 Mac 데스크톱 앱에서만 실제로 검증했습니다.
- **테스트 계정:** 사용자 콤보 실서버 테스트용 계정 2개(`qa-combo-a-…`, `qa-combo-b-…@example.com`)가 Supabase Authentication에 남아 있어 직접 삭제가 필요합니다.
