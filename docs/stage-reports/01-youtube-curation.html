MARTIALDEX — 기술별 YouTube 영상 데이터 큐레이션 작업

작업 일자: 2026-08-14 · 작성: Claude (개발 어시스턴트)

1. 작업 개요

MARTIALDEX의 각 기술 상세 페이지에 표시되는 "관련 영상"은 YouTube Data API를 전혀 사용하지 않고, 사람이 직접 웹 검색으로 확인한 실존 영상만 data/curated/videos.json에 수동으로 등록하는 방식으로 운영된다. 이번 세션은 이전에 토큰 소진으로 중단되었던 이 큐레이션 작업을 이어서 진행한 것이다.

준수한 원칙

  • YouTube Data API, API Key를 전혀 사용하지 않는다.
  • 웹 검색으로 실제 존재하는 영상만 등록하고, 영상 제목/videoId/채널명을 정확히 기록한다.
  • 기술당 최대 2개, 경기 하이라이트·쇼츠보다 기술 설명 튜토리얼을 우선한다.
  • 이미 등록된 영상은 재검색하지 않고, 적절한 영상이 없으면 억지로 추가하지 않는다.

2. 작업 방식

5개의 서브 에이전트를 병렬로 실행해 BJJ 기술 40개에 대해 WebSearch/WebFetch로 실제 튜토리얼 영상을 검색·검증하도록 지시했다. 이후 YouTube oEmbed API로 70개 videoId 전수를 직접 재검증하여 (1) 영상이 실제로 존재하는지, (2) 제목/채널명이 에이전트가 보고한 내용과 일치하는지 대조했다. 검증을 통과한 데이터만 data/curated/videos.json에 병합했다.

4. 다음 이어서 작업할 범위

BJJ 기술 나머지(256개) 중 bjj__hip-control부터 순서대로 계속 진행한다. 이번에 건너뛴 3개 기술은 이후 다른 검색어로 재시도할 수 있으며, 계속 찾지 못하면 계속 생략한다.

비고. 진행 상황은 data/curated/videos.json에 직접 저장되므로 파일에 영구 보존된다. 이후 세션에서 동일한 방식(웹 검색 → oEmbed 재검증 → 병합)으로 계속 이어갈 수 있다.
