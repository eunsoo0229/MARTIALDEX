2. 발견하고 수정한 문제

죽은 코드 2건 제거. useRecentlyViewed(더 이상 쓰이지 않는 구버전 훅, useRecentlyViewedSynced로 대체됨)와 totalMartialArtCount(아무 곳에서도 참조되지 않음)를 삭제.
QA 스크립트 자체의 버그 2건. localStorage.clear() 후 페이지를 리로드하지 않아 "빈 상태" 테스트가 잘못 실패하던 것, Node 컨텍스트에서 document를 참조하던 죽은 코드 — 앱 코드가 아닌 테스트 스크립트 자체의 문제였음을 확인하고 수정.

앱 로직 자체의 버그는 발견되지 않았고, 플레이스홀더·더미 데이터도 없었다.

4. Production Build

npx tsc --noEmit 통과, npm run build 성공. 빌드 산출물에 API 키/Gemini 엔드포인트 문자열이 없음을 재확인해 보안 요건을 유지했다.

5. README.md 작성

프로젝트 소개, 실행 방법, 폴더 구조, 데이터 구조/파이프라인, 마크다운 추가 방법, YouTube 설정 (API 미사용 근거), AI(Gemini) 설정과 provider 분리 구조, 환경변수 설정, 배포 방법을 문서화했다. 폴더 구조는 실제 파일 목록과 대조해 검증했다.
