MARTIALDEX — 학습 커리큘럼 시스템 구현

작업 일자: 2026-08-14 · 작성: Claude (개발 어시스턴트)

1. 개요

기존 백과사전·검색·필터·YouTube·AI 기능을 훼손하지 않는 선에서, (1) Martialdex가 설계한 무술별 추천 커리큘럼, (2) 사용자가 직접 만드는 개인 커리큘럼, (3) 커리큘럼을 다른 사람과 공유하는 기능, 세 축을 구현했다.

모두 30~60일 범위 안에서, 무술마다 실제 기술 데이터(category/difficulty/원문 순서)를 기반으로 서로 다른 단계 구조를 설계했다 — 균일 분할이 아니다.

학습 구조 예시

주짓수: 기본 움직임 → 스탠딩/테이크다운 → 기본 포지션 → 가드 기초 → 가드 응용 → 이스케이프 → 가드 패스 → 기본 서브미션 → 레그락/백 서브미션 → 포지션 전환.

복싱: 기본 자세/풋워크 → 기본 펀치 → 기본 방어 → 거리 조절 → 콤비네이션 → 방어-공격 연결 → 상황별 응용.

관절기·던지기·조르기 구간은 하루 기술 수를 줄이고 안전 안내를 강화했다.

3. 새로 만든 파일

scripts/generate-curriculum.mjs(생성기, 실제 기술 ID만 참조·검증) · data/curriculum/official/*.json(9개 + 요약) · src/lib/curriculum/{types, officialData, repository, curriculumService, shareCode, useCurriculum}.ts · src/pages/{LearningHub, CurriculumList, CurriculumDayList, CurriculumDayDetail, CurriculumEditor, Community}.tsx · .devtools/qa-curriculum.mjs

4. 수정한 파일

App.tsx(라우팅) · Header.tsx(학습/커뮤니티 메뉴) · AiAskModal.tsx + ai/context.ts(Day 컨텍스트 추가) · Home.tsx(모바일 진입 버튼) · global.css · README.md. 기존 파일 삭제나 기존 데이터 재생성은 없었다.

5. 사용자 커스텀 커리큘럼

이름/설명/대표무술/공개여부/커버아이콘 설정, Day 추가·삭제·순서변경(▲▼), 기술 검색-추가/제거 (모든 무술 대상, 실제 백과사전 기술만 선택 가능 — 가짜 기술 생성 불가), 학습목표/예상시간 편집을 모두 구현하고 테스트했다.

6. 공유 기능 범위

백엔드·사용자 계정이 없어 실제 서버 커뮤니티는 만들지 않았다. 대신 공유 코드 (MDCUR1. + base64 JSON)로 실제 작동하는 로컬-우선 공유를 구현했다: 복사 → 전달 → 가져오기 시 미리보기 → "내 커리큘럼에 추가"(원본 훼손 없이 새 복사본 생성, 존재하지 않는 기술 ID는 자동 제외). 

UI
  ↓
Curriculum Service
  ↓
CurriculumRepository (interface)
  ↓
LocalCurriculumRepository (지금 유일한 구현체)
  → 향후 Firebase/Supabase 등 원격 Repository로 교체 가능 (UI/서비스 변경 없음)

좋아요/사용횟수는 현재 로컬 전용이라는 점을 UI에 명시했다.
