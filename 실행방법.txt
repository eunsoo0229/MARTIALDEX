MARTIALDEX 실행 방법
====================

1. 터미널(터미널.app)을 엽니다.

2. 프로젝트 폴더로 이동합니다.
   cd /Users/swcho/Documents/MARTIALDEX

3. 앱을 실행합니다. (Electron 창이 뜹니다)
   npm run dev

4. 종료할 때는 터미널에서 Ctrl + C 를 누릅니다.


참고
----
- 맨 처음 한 번, 또는 node_modules 폴더가 없을 때만:
  npm install

- AI에게 질문 기능을 쓰려면 .env 파일에 GEMINI_API_KEY가 설정되어 있어야 합니다.
  (.env.example 참고)

- Electron 창 없이 브라우저에서만 미리보고 싶을 때:
  npm run dev:vite
  (이 모드에서는 AI 질문, YouTube 외부 링크 열기가 동작하지 않습니다)

- 실제 배포용 파일(빌드) 오류만 확인하고 싶을 때:
  npm run build
